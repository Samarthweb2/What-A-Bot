# Reusable Handoff Prompt Template

Use for every handoff between surfaces after the initial kickoffs.

```
OBJECTIVE: <one line -- what you need from this surface right now>
FILES/SNAPSHOT: <@file refs, or pasted code/text -- only what's needed>
CONSTRAINTS: plan is locked, don't expand scope; Windows/PowerShell;
             <anything specific to this handoff>
COMPLETED: <what's already verified working, so it isn't redone>
FAILURE (if diagnosing): <exact symptom, exact repro steps>
EXPECTED OUTPUT: <diff / verdict / test file / go-no-go -- be specific>
```
